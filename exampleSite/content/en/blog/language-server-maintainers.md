## How do you decide which issue to fix first?

> Fix the issues that cost people's trust first. People forgive completion that is not clever enough; once go-to-definition jumps to the wrong place, they stop using it.

## Advice for editor developers

**Get the bug report format right.** When users can attach a replayable log of requests, fixing an issue goes from days to minutes.
